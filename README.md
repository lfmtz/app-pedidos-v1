# Automotive Operations Automation Tool (Stellantis)

## Goal
To streamline and automate the internal vehicle ordering and tracking process at a major Nissan/Stellantis dealership.

## Business Impact
* **Efficiency:** Reduced operational processing time by **40%**.
* **Accuracy:** Eliminated manual data entry errors by centralizing order management.
* **Visibility:** Provided real-time tracking for the sales team.

## Tech Stack
* **Python:** Core logic and data processing.
* **Automation:** Workflow optimization for internal orders.

## Key Features
* Automated order generation.
* Centralized dashboard for sales status.
* Optimization of administrative tasks for the sales department.
